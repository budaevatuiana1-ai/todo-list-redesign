# Мой список дел

Веб-приложение «Мой список дел» — простой список задач (todo-лист), который
помогает записывать дела, отмечать выполненные и удалять ненужные. Это
переработанная версия приложения: вместо оформления под старые версии Windows
сделан современный, минималистичный дизайн.

## Какую задачу решает приложение

Приложение помогает не держать дела в голове: вы записываете задачи в список,
по мере выполнения отмечаете их галочкой, а лишние — удаляете. Все задачи
сохраняются в браузере, поэтому список остаётся на месте после перезагрузки
страницы.

## Для кого оно предназначено

Для всех, кому нужен простой личный список дел на каждый день — без
регистрации, установки и лишних настроек. Достаточно открыть страницу в
браузере.

## Основные функции

- **Добавление задачи** — введите текст в поле и нажмите кнопку «Добавить» или
  клавишу Enter.
- **Отметка о выполнении** — поставьте галочку у задачи; она выделяется
  приглушённым цветом и зачёркнутым текстом.
- **Удаление задачи** — нажмите кнопку «удалить» у нужной записи.
- **Счётчики** — рядом с заголовком блока «Задачи» показывается, сколько всего
  задач и сколько из них выполнено.
- **Сохранение данных** — список хранится в браузере (localStorage) и
  сохраняется между визитами.
- **Адаптивная вёрстка** — на узких экранах (телефоны) интерфейс
  перестраивается в одну колонку.

## Инструкция по использованию

1. Введите текст задачи в поле «Что нужно сделать?».
2. Нажмите «Добавить» или клавишу Enter — задача появится в списке.
3. Чтобы отметить задачу выполненной, поставьте галочку слева от неё.
4. Чтобы удалить задачу, нажмите кнопку «удалить» справа от неё.
5. Следите за счётчиками «Всего» и «Выполнено» в заголовке блока «Задачи».

## Использованные технологии

- **HTML5** — разметка страницы (`index.html`).
- **CSS3** — оформление, адаптивная вёрстка (`style.css`).
- **JavaScript** — логика работы со списком (`script.js`).
- **localStorage** — хранение задач прямо в браузере, без сервера.

Приложение работает без сервера, сборки и сторонних библиотек.

## Структура файлов

```
todo-list-redesign/
├── index.html     — разметка экрана
├── style.css      — стили и адаптивная вёрстка
├── script.js      — логика: добавление, отметка, удаление, счётчики
├── REFERENCE.md   — описание желаемого дизайна
└── ЗАПУСК.md      — заметки по запуску стартового проекта
```

## Локальный запуск

Никакие `npm install` и серверы не нужны. Просто откройте `index.html`
двойным щелчком (или через File → Open в браузере).

Если браузер ругается на `localStorage` при открытии файла напрямую
(`file://`), запустите локальный сервер в папке проекта и откройте
`http://localhost:8000`:

```bash
python -m http.server 8000
```
