# Запуск стартового проекта

Простой список задач (todo-лист) без сервера и без сборки — достаточно
открыть страницу в браузере.

## Как запустить

Просто откройте `index.html` двойным щелчком (или через File → Open в
браузере). Никаких `npm install` и серверов не нужно.

Если браузер ругается на `localStorage` при открытии файла напрямую
(`file://`) — запустите локальный сервер одной командой в этой папке и
откройте `http://localhost:8000`:

```bash
python3 -m http.server 8000
```

## Что нужно сделать

Задача — переработать вёрстку и стили (`style.css`, при необходимости
разметку в `index.html`), ориентируясь на референс (`REFERENCE.md`),
**не меняя логику** в `script.js`: добавление задачи, отметка
выполненной, удаление и счётчики (сейчас они отображаются рядом с
заголовком блока «Задачи») должны продолжать работать как есть.

Файлы:

- `index.html` — разметка экрана
- `style.css` — стили (основное поле для доработки)
- `script.js` — логика (добавление/отметка/удаление задач, сохранение
  в localStorage) — трогать не обязательно
- `REFERENCE.md` — описание желаемого результата
