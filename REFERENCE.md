# Референс — каким должен стать результат

Текущий вид — стилизация под старые версии Windows (серый фон, шрифт
Times New Roman, объёмные рамки 3D-стиля, задачи визуально не
отличаются друг от друга).

## К чему нужно прийти

- **Цвета** — светлый нейтральный фон (белый/очень светло-серый),
  один акцентный цвет для кнопок и активных элементов (например,
  спокойный синий или зелёный).
- **Типографика** — современный шрифт без засечек (system-ui,
  "Segoe UI", "Inter" или похожий), без теней у заголовка.
- **Карточки задач** — каждая задача должна быть визуально обособлена
  (лёгкая тень или разделитель, отступы), не сплошной список впритык.
- **Выполненные задачи** — чёткое визуальное отличие (например, галочка
  + приглушённый цвет текста), но без агрессивного зачёркивания на весь
  экран.
- **Кнопка добавления** — крупная, заметная, с закруглёнными углами,
  без 3D-рамок.
- Общий вид — минималистичный, «воздушный» (достаточно отступов между
  блоками), одна колонка, всё умещается на одном экране без лишней
  прокрутки.
